Quick start

Elements and tags

Every HTML tag is a function exported by fiorejs. Calling it creates the element with document.createElement and returns that element, so the result goes into the DOM like any other node.

One function per tag

fiorejs exports a function for each HTML element: div, p, button, input and so on. A tag called with a string, a number or a node uses it as the children: 

import { div, p, strong } from 'fiorejs';

const box = div([p(['Hello, ', strong('fiore')]), p('Second paragraph')]);

document.body.append(box);
console.log(box.outerHTML);
// <div><p>Hello, <strong>fiore</strong></p><p>Second paragraph</p></div>
          
const box = (
  <div>
    <p>
      Hello, <strong>fiore</strong>
    </p>
    <p>Second paragraph</p>
  </div>
);

document.body.append(box);
console.log(box.outerHTML);
// <div><p>Hello, <strong>fiore</strong></p><p>Second paragraph</p></div>

Tags whose names are reserved words in JavaScript get a trailing underscore. The var element is exported as var_, and switch in the SVG module as switch_.

In JSX a lowercase tag name is an element and you import nothing. The names are the HTML names, so <var> needs no underscore. A name with a hyphen, such as <user-card>, is a custom element.

What a tag returns

A tag returns the native element, not a wrapper. There is nothing to unwrap, and every DOM method and property is available at once. The TypeScript type is exact for the tag: input returns HTMLInputElement, canvas returns HTMLCanvasElement, a returns HTMLAnchorElement. 

import { canvas, input } from 'fiorejs';

const field = input.props({ type: 'email' }).create();
const surface = canvas.props({ width: 300, height: 150 }).create();

console.log(field instanceof HTMLInputElement, surface instanceof HTMLCanvasElement);
console.log(typeof surface.getContext);
          
const field = <input type="email" />;
const surface = <canvas width="300" height="150" />;

console.log(field instanceof HTMLInputElement, surface instanceof HTMLCanvasElement);
console.log(typeof surface.getContext);

The same exact types check the props, the attributes and the listeners you pass, so input.props({ valu: 'x' }) is a type error. See Props and attributes and Events.

JSX is typed per element too, so <input valu="x" /> is a type error. The expression itself is typed as Node; cast it when you need the element type: (<input />) as HTMLInputElement. At run time you get the exact native element.

Plain calls

A tag called directly takes one argument. A plain object is the data object, with the keys props, attrs, on and children. Anything else, such as a string, an array or a node, is the children:

JSX has no data object. The props go on the tag and the children go between the tags; Props and attributes explains how each prop is applied:

import { p, strong } from 'fiorejs';

const lead = p({
  props: { className: 'lead' },
  attrs: { title: 'Intro' },
  on: { click: () => console.log('clicked') },
  children: ['Hello, ', strong('fiore')],
});

document.body.append(lead);
          
const lead = (
  <p className="lead" title="Intro" onclick={() => console.log('clicked')}>
    Hello, <strong>fiore</strong>
  </p>
);

document.body.append(lead);
Data that is not yours. A plain object is always read as the data object. If a value comes from parsed JSON, storage or a message, pass it through .create(value) or { children: value }. Otherwise an object such as { "props": { "innerHTML": "..." } } sets properties instead of showing text.
Data that is not yours. Put a value between the tags and it is shown as text. Do not spread an object whose keys come from users, as in <div {...value} />: a key such as innerHTML would set that property.

Builders

JSX has no builders. Everything a builder sets goes on the tag as props, and a reusable template is a component, a function that returns JSX; see Components and state. The builder example below does the same as the JSX one:

A tag also starts a builder. props, attrs, on, with, also and create are methods of the tag itself, so div.props(...) needs no call before it. A builder records its settings and creates the element only at .create(): 

import { button } from 'fiorejs';

const save = button
  .props({ type: 'submit', className: 'primary' })
  .attrs({ 'aria-label': 'Save the form' })
  .on({ click: () => console.log('save') })
  .create('Save');

document.body.append(save);
          
const save = (
  <button type="submit" className="primary" aria-label="Save the form" onclick={() => console.log('save')}>
    Save
  </button>
);

document.body.append(save);

Use a plain call for a static element with little configuration, and a builder when you need props and attrs apart, several listeners, or a reusable template. Builders covers the methods in detail.

Elements by name

In JSX the tag name already is the element name, so <user-card> is a custom element and <tr> is a row. There is no element() to call.

element(name) returns the tag of any element by its name, with the same methods as a named export. It is useful when the name is data, or for an element that has no named export, such as a custom element. A name with a hyphen, such as element('user-card'), is typed as a custom element tag that takes any attribute: 

import { element } from 'fiorejs';

const card = element('user-card');
const row = element('tr');

document.body.append(
  card.attrs({ name: 'Ada' }).create('Ada Lovelace'),
  row({ children: 'a row outside a table' }),
);
          
document.body.append(
  <user-card name="Ada">Ada Lovelace</user-card>,
  <tr>a row outside a table</tr>,
);

element('div') returns a tag equivalent to div. The SVG and MathML modules export their own element, which creates elements in their namespace; see SVG and MathML.

Import styles

JSX needs no imports for tags. The example below shows the import styles of the builder.

Named imports from fiorejs are the usual style and let a bundler drop the tags you do not use. Each namespace is also available as a single object: 

import html from 'fiorejs/html';
import svg from 'fiorejs/svg';

const { div, span } = html;

document.body.append(div([span('Text'), svg.svg.attrs({ width: '10', height: '10' }).create()]));

Installation lists every entry point. The list of all exported tags is in the API reference.
