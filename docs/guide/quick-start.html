Quick start

fiore creates real DOM elements with one function per tag. Add @fiorejs/signals and bound spots of the page update on their own. This page gets you from nothing to a working counter in a few minutes.

Try it without installing

The interactive tutorial runs fiore in your browser, with an editor and a live preview for every lesson. It is the fastest way to learn the API.

Open the tutorial →

Start a new project

npm create @fiorejs asks for the build tool, the language, JSX and signals, then writes a ready project: 

npm create @fiorejs my-app
cd my-app
npm install
npm run dev

The defaults are Vite, TypeScript, JSX and signals. See Create a project for every option.

JSX is on by default, so the project is already set up for @fiorejs/jsx and you can write the examples of this site as JSX straight away.

Builders work with or without JSX, so you can answer no to the JSX question, or pass --no-jsx.

Add fiore to a project

npm install fiorejs @fiorejs/signals
npm install fiorejs @fiorejs/signals @fiorejs/jsx

@fiorejs/jsx is the JSX runtime. Point your compiler at it with jsxImportSource; JSX shows the setting for each tool.

Both packages are plain ES modules with TypeScript declarations and no runtime dependencies. @fiorejs/signals is optional; leave it out if the page does not need to update. See Installation for import maps and CDNs.

Your first element

Every HTML tag is a function. Call it with the children, or start a builder with props, attrs or on and finish with create. Either way you get the native element back:

Write the tag as markup. Each JSX expression creates its elements once and gives you the native DOM nodes back, with the same functions underneath:

import { h1, p, button } from 'fiorejs';

document.body.append(
  h1('Hello, fiore'),
  p('Elements are plain DOM nodes.'),
  button.on({ click: () => alert('Clicked') }).create('Click me'),
);
document.body.append(
  <h1>Hello, fiore</h1>,
  <p>Elements are plain DOM nodes.</p>,
  <button onclick={() => alert('Clicked')}>Click me</button>,
);

Make it update

A signal holds a value. Put it where a child, a prop or an attribute goes, and that spot updates when the value changes. Nothing else re-renders: 

import { button, p } from 'fiorejs';
import { state } from '@fiorejs/signals';

const count = state(0);

document.body.append(
  button.on({ click: () => count.update((n) => n + 1) }).create('Add one'),
  p(['Clicked ', count, ' times']),
);
import { state } from '@fiorejs/signals';

const count = state(0);

document.body.append(
  <button onclick={() => count.update((n) => n + 1)}>Add one</button>,
  <p>Clicked {count} times</p>,
);

count is bound in the paragraph, so only that text changes on a click. The update runs on a microtask, after the click handler finishes.
