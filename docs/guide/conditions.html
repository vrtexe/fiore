Quick start

Conditional rendering

A component is a function that takes a props object and runs once, so a plain conditional in markup is decided once. signal.if and signal.case are the live versions: they switch between branches when the signal changes and build only the branch that is shown.

Why a plain conditional does not switch

In div(open.get() ? a : b), open.get() is read once while the element is created, so the result never changes. A live conditional is a value that fiorejs binds, like any other signal.

In <div>{open.get() ? a : b}</div>, open.get() is read once while the element is created, so the result never changes. A live conditional is a value that fiorejs binds, like any other signal.

signal.if and else

signal.if(then) shows what then returns while the value of the signal is truthy, and nothing otherwise. .else(otherwise) adds the other branch. Both branches are functions, so only the shown branch is built. 

import { div, em, p } from 'fiorejs';
import { state, flush } from '@fiorejs/signals';

const open = state(false);

const details = () => {
  console.log('build details');
  return p('The details');
};

const view = div(open.if(details).else(() => em('closed')));
document.body.append(view);
console.log(view.innerHTML); // <em>closed</em>, details was not built

open.set(true);
flush(); // logs "build details"
console.log(view.innerHTML); // <p>The details</p>
import { state, flush } from '@fiorejs/signals';

const open = state(false);

const details = () => {
  console.log('build details');
  return <p>The details</p>;
};

const view = <div>{open.if(details).else(() => <em>closed</em>)}</div>;
document.body.append(view);
console.log(view.innerHTML); // <em>closed</em>, details was not built

open.set(true);
flush(); // logs "build details"
console.log(view.innerHTML); // <p>The details</p>

A branch is built once, when it is shown, and rebuilt only when the truthiness flips. count.if(...) does not rebuild when count goes from 1 to 2. When the branch changes, the bindings and effects the old branch created stop.

To branch on something derived, use a computed: count.computed((n) => n > 10).if(...). Without .else, nothing is shown while the value is falsy.

What a branch returns

A branch returns text, a node or nothing. It does not track signals itself, since it runs once when it is shown. To show a live value inside a branch, put it in an element: .else(() => span(user.computed((u) => u.name))).

A branch that throws while it is built keeps the nodes the binding had and stops updating, like any binding that throws. The error is thrown at the end of the flush.

signal.case and else

For more than two branches, signal.case(match, render) shows what render returns while the value matches. A function as match is a test on the value; any other value is compared with Object.is. Chain more cases, and add .else(otherwise) for the rest. The first case that matches wins. Without .else, nothing shows when no case matches. 

import { div, em, span } from 'fiorejs';
import { state, flush } from '@fiorejs/signals';

const status = state('loading');

const view = div(
  status
    .case('loading', () => span('Loading'))
    .case('error', () => em('Something went wrong'))
    .case((value) => value.startsWith('done'), () => span('Done'))
    .else(() => null),
);
document.body.append(view);

status.set('done: 3 rows');
flush();
console.log(view.textContent); // Done

status.set('idle');
flush();
console.log(view.textContent); // empty: no case matches and else gives nothing
import { state, flush } from '@fiorejs/signals';

const status = state('loading');

const view = (
  <div>
    {status
      .case('loading', () => <span>Loading</span>)
      .case('error', () => <em>Something went wrong</em>)
      .case((value) => value.startsWith('done'), () => <span>Done</span>)
      .else(() => null)}
  </div>
);
document.body.append(view);

status.set('done: 3 rows');
flush();
console.log(view.textContent); // Done

status.set('idle');
flush();
console.log(view.textContent); // empty: no case matches and else gives nothing

A branch is rebuilt only when another case wins. Moving from 'done: 3 rows' to 'done: 4 rows' keeps the same branch. .if(then) is the case Boolean, so .if(then).case(...) works too. To match a function value itself, test it with .case((value) => value === handler, ...).
